# PeroChat UI Design Specification

## 1. 개요 (Overview)

- **컨셉:** '니디 걸 오버도즈' 풍의 Y2K 레트로 퓨처리즘 & 불안정한 디지털 감성
- **핵심 UX:** 대화의 몰입도에 따라 레이아웃이 유동적으로 변하는 가변형(Fluid) UI
- **텍스트 형식:** 소설형 (대사 + 지문 혼합, 700~1000자 응답)
- **기반:** LLM 실시간 생성

---

## 2. 화면 구조 (Screen Layout)

화면은 세로로 3단 구성. **Header와 Footer는 고정**, **Main 영역**만 모드에 따라 변화.

| 영역 | 높이 | 역할 | 스타일 |
|------|------|------|--------|
| **Header** | 50px (Fixed) | 시스템 상태 (멘탈, 시간, 접속 상태) | 윈도우 95/98 타이틀 바 |
| **Main** | Flex (Auto) | 이미지 + 텍스트 블록 표시 | 모드에 따라 가변 |
| **Footer** | 80px (Fixed) | 사용자 입력창 | 콘솔 터미널 스타일 |

---

## 3. 텍스트 블록 분할 규칙

### 3.1. 블록 단위
**대사 → 지문(행동 묘사) 순서로 한 블록 구성**

```
[블록 1]
**나은** | "...거짓말."
낮게 읊조린 목소리가 방 안에 울렸다. 그녀는 시선을 피했다.

[블록 2]
**수아** | "...거짓말이 아니야."
그녀는 한 발짝 다가섰다. 손을 내밀었지만, 이내 멈췄다.

[블록 3]
**나은** | "그만해."
차갑게 내뱉었다.
```

### 3.2. 지문으로 시작하는 경우 (도입부 등)
```
[블록 0]
창밖으로 비가 내렸다. 네온사인이 젖은 유리창에 번졌다.

[블록 1]
**나은** | "왜 왔어."
...
```

### 3.3. 대사 표기 형식
```
**캐릭터명** | "대사 내용"
```
- LLM이 캐릭터명을 정확하게 출력하므로, 클라이언트에서 파싱하여 캐릭터 이미지 매칭에 활용
- 대사는 큰따옴표(`""`)로 표기

---

## 4. 스크롤 스냅 방식

### 4.1. 동작 원리
- 스크롤 시 **블록 단위로 스냅**
- 현재 읽는 블록이 **화면 중앙**에 위치
- 위/아래 블록은 **흐리게(블러/투명도)** 표시

### 4.2. 레이아웃 (일반 모드)
```
┌────────────────────────────────────────────────────────┐
│ ♥ MENTAL: UNSTABLE                          REC ●     │
├──────────────────────┬─────────────────────────────────┤
│                      │   ░░░ 이전 블록 (흐림) ░░░        │
│                      │                                 │
│    [캐릭터 이미지]    │   ████ 현재 블록 (선명) ████      │
│                      │                                 │
│                      │   ░░░ 다음 블록 (흐림) ░░░        │
│       (40%)          │            (60%)                │
├──────────────────────┴─────────────────────────────────┤
│ >_ 메시지를 입력하세요...                    [SEND]      │
└────────────────────────────────────────────────────────┘
```

### 4.3. CSS 구현
```css
.text-container {
  scroll-snap-type: y mandatory;
  overflow-y: scroll;
  mask-image: linear-gradient(
    to bottom,
    transparent 0%,
    black 30%,
    black 70%,
    transparent 100%
  );
}

.block {
  scroll-snap-align: center;
  scroll-snap-stop: always;
  min-height: 60vh;
  display: flex;
  align-items: center;
}
```

## 5. 캐릭터 이미지 표시 로직

### 5.1. 기본 규칙
- 현재 블록에 등장하는 캐릭터 이미지 표시
- **복수 캐릭터 가능** (한 블록에 두 명 이상 등장 시 모두 표시)
- 지문만 있는 블록: **마지막으로 등장한 캐릭터** 유지

### 5.2. 캐릭터 감지
```javascript
// 스크롤 스냅 완료 시 현재 블록의 캐릭터 추출
container.addEventListener('scrollend', () => {
  const current = getCurrentBlock()
  const characters = extractCharacters(current) // ["나은"] or ["나은", "수아"]
  updateCharacterDisplay(characters)
})

// 대사 패턴: **캐릭터명** | "대사"
const dialoguePattern = /\*\*(.+?)\*\*\s*\|\s*"(.+?)"/g
```

### 5.3. 이미지 전환 애니메이션
```css
.character-image {
  transition: opacity 0.3s ease-out;
}
```

### 5.4. 이미지 리소스
- 미리 저장된 이미지를 조건에 맞게 출력
- 캐릭터별 기본 이미지 필수
- 감정별 바리에이션은 추후 확장 가능

## 6. 모드별 상세 명세

### 6.1. 일반 대화 모드 (Normal Mode)

| 항목 | 값 |
|------|-----|
| 레이아웃 | 좌우 분할 (40:60) |
| 좌측 | 캐릭터 스탠딩 + 기본 배경 |
| 우측 | 텍스트 블록 (스크롤 스냅) |
| 텍스트 배경 | 불투명 (Solid) 다크 |

### 6.2. 이벤트 모드 (Event Mode)

| 항목 | 값 |
|------|-----|
| 레이아웃 | 전체 통합 (Overlay) |
| 배경 | 풀 일러스트 CG (100%) |
| 텍스트 영역 | 중앙 배치, 가로폭 축소, 반투명 |
| 텍스트 배경 | Glassmorphism (Opacity 50~70% + Blur) |

#### 이벤트 모드 레이아웃
```
┌────────────────────────────────────────────────────────┐
│ Header                                                 │
├────────────────────────────────────────────────────────┤
│                                                        │
│                    ┌─────────────────────┐             │
│                    │ ░░░ 이전 블록 ░░░    │             │
│  [풀 일러스트 CG]   │ ████ 현재 블록 ████  │ ← 반투명    │
│                    │ ░░░ 다음 블록 ░░░    │             │
│                    └─────────────────────┘             │
│                                                        │
├────────────────────────────────────────────────────────┤
│ Footer                                                 │
└────────────────────────────────────────────────────────┘
```

**대안 (필요 시 전환 가능):**
- 텍스트 영역을 우측 끝에 고정, 세로 전체 차지, 가로폭만 축소 (35%)

## 7. 전환 애니메이션

### 7.1. 트리거
- LLM 응답 내 이벤트 마커 감지 시
- 예: `[EVENT:CG_happy]`, `[MODE:event]` 등 (형식 추후 정의)

### 7.2. 애니메이션 속성
```css
transition: all 0.5s ease-in-out;
```

### 7.3. 동작 시퀀스
1. **확장:** 배경 이미지 컨테이너 `width: 40% → 100%`
2. **투명화:** 텍스트 컨테이너 배경 `solid → rgba(0,0,0,0.6)`
3. **교체:** 배경 이미지 크로스페이드 (기본 → 이벤트 CG)

---

## 8. UI 컴포넌트 디자인 가이드

### 8.1. 타이포그래피

| 용도 | 폰트 스타일 |
|------|------------|
| 시스템 (헤더, 메뉴) | 도트(Pixel) 폰트 |
| 지문 (나레이션) | 명조체 (Serif), 가독성 우선 |
| 대사 | 고딕체 또는 명조체 + 색상 강조 |
| 글리치 효과 | 특정 강조 단어에만 제한적 사용 |

### 8.2. 텍스트 스타일
```css
/* 지문 */
.narration {
  color: #CCCCCC;
  line-height: 1.8;
  font-family: 'Noto Serif KR', serif;
}

/* 대사 */
.dialogue {
  color: #FF77FF;
  font-weight: 500;
}

/* 캐릭터명 */
.character-name {
  color: #00FFFF;
  font-weight: bold;
}
```

### 8.3. 컬러 팔레트

| 용도 | 색상 코드 |
|------|----------|
| Primary (기본 배경) | `#1A0033` 딥 다크 퍼플 |
| Secondary (강조, 버튼) | `#FF00FF` 네온 핑크 |
| Text (기본) | `#FFFFFF` 화이트 |
| Text (시스템) | `#00FFFF` 사이안 |
| Overlay | `#000000` (투명도 조절) |

### 8.4. 입력창 (Footer)

- **디자인:** 콘솔 터미널 스타일
- **커서:** 깜빡이는 언더바 (`_`)
- **입력 방식:** 직접 입력 (추천 선택지 보조 제공 가능)
- **피드백:**
  - 일반: 차분한 테두리
  - 이벤트: 붉게 빛나거나 미세 진동

---

## 9. 타이핑 효과

- **단위:** 한 블록(문단)씩
- **방식:** LLM 스트리밍에 맞춰 자연스럽게 표시
- **스킵:** 탭/클릭으로 즉시 전체 표시 (옵션)

---

## 10. 필요 리소스 (Assets)

### 10.1. 일반 모드
- 캐릭터 스탠딩 (투명 배경 PNG)
- 기본 배경 텍스처 (반복 가능한 패턴 또는 심플한 방)

### 10.2. 이벤트 모드
- 풀 일러스트 CG (16:9 권장)
- 상황별 바리에이션 (애정, 분노, 우울 등)

### 10.3. UI 요소
- 레트로 스타일 아이콘 (하트, 경고창, 닫기 버튼)
- 노이즈/스캔라인 오버레이 이미지

## 11. 개발 참고용 구조

```html
<div class="game-container">

  <header class="ui-header">
    <span>♥ MENTAL: UNSTABLE</span>
    <span>REC ●</span>
  </header>

  <main class="main-stage normal-mode">

    <!-- 이미지 영역 -->
    <div class="visual-layer">
      <img src="background.jpg" class="bg-img" />
      <img src="character.png" class="char-img" />
    </div>

    <!-- 텍스트 영역 -->
    <div class="text-layer">
      <div class="block" data-characters="나은">
        <span class="character-name">나은</span>
        <span class="dialogue">"...거짓말."</span>
        <p class="narration">낮게 읊조린 목소리가 방 안에 울렸다.</p>
      </div>
      <div class="block" data-characters="수아">
        <span class="character-name">수아</span>
        <span class="dialogue">"...거짓말이 아니야."</span>
        <p class="narration">그녀는 한 발짝 다가섰다.</p>
      </div>
    </div>

  </main>

  <footer class="ui-footer">
    <span class="prompt">>_</span>
    <input type="text" placeholder="메시지를 입력하세요..." />
    <button class="btn-send">SEND</button>
  </footer>

</div>
```

## 12. 반응형 고려사항 (추후 정의 필요)

- 브레이크포인트 정의 필요
- 터치 스크롤 스냅 동작 테스트 필요

## 13. 접근성 고려사항 (추후 정의 필요)

- 반투명 배경에서 텍스트 가독성 검증
- 네온 컬러 대비율 확인
- 글리치 효과 사용 제한 (광과민성)
